# ルール内容
AIエージェントへ与える具体的な指示やコーディング規約を記載します。
```

# エージェントスキルの設定 (.cursor/skills)
AIエージェントに特定のタスク（PRの作成や特定デプロイ手順など）の専門知識を教え込むには、Agent Skills機能を使用します。

* ディレクトリ作成: `.cursor/skills/<スキル名>/` フォルダを作成する。
* ファイル作成: フォルダ内に `SKILL.md` を配置する。
* 記述形式: 必須の `name` と `description` を含むYAMLフロントマターを記述する。
```markdown
---
name: "skill-name"
description: "このスキルを使うべき条件や説明"
---
# スキルの手順
エージェントが実行すべき手順を記載します。
```
* 起動方法: エージェントチャット（`Ctrl + I` または `Cmd + I`）で `/` を入力すると自動検出・呼び出しが可能になります。

# カスタムサブエージェントの設定 (.cursor/agents)
特定の検証や処理を行うカスタムサブエージェントを定義できます。

* ディレクトリ作成: `.cursor/agents/` フォルダを作成する。
* ファイル作成: `verifier.md` などのマークダウンファイルを配置する。
* 記述形式: `name` と `description` を持たせたフロントマターと、AI用プロンプトを記述する。
